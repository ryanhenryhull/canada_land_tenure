# About
This viewer was made in the Quantitative Biodiversity Lab at McGill University. It gathers provincial and national datasets related to land tenure across Canada. It is non-authoritative and non-comprehensive. Indigenous land datasets do not include traditional and ancestral territories, which can be found on Native-Land.ca
